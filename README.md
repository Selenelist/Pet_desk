# Pet Desk v0.1.0

一个用 Electron + 原生 HTML/CSS/JS 做的桌面猫猫宠物。打开后，猫猫会以透明、无边框、置顶窗口显示在桌面上，可以拖动、互动、散步，也可以定时提醒休息。

当前版本优先保证 macOS 可运行，项目结构保留了后续兼容 Windows 的空间。

## 功能

- 透明无边框桌宠窗口
- 猫猫视频动作播放
- 双击打开动作菜单
- 鼠标拖动猫猫
- 菜单散步和拖到左右边缘自动散步
- 逗猫、摸摸头、摸肚皮互动模式
- 休息提醒气泡和猫叫提示
- 控制面板调节猫咪大小
- 控制面板设置休息提醒间隔
- 小猫状态系统：心情、饱腹、水分、精力
- 本地保存猫咪大小、提醒间隔和小猫状态

## 运行

```bash
npm install
npm start
```

启动后会出现猫猫窗口：

- 单击猫猫：停止当前动作或关闭提醒气泡
- 双击猫猫：打开动作菜单
- 拖动猫猫：移动到桌面任意位置附近
- 点击菜单“设置”：打开控制面板
- 点击菜单“退出”：退出应用

## 素材目录

项目会自动读取每个动作文件夹里的第一个可用视频文件：

```text
assets/cat/
  idle/
  walk/
  happy/
  play/
  touch/
  eat/
  drink/
  sleep/
  source/
```

支持格式：

```text
.webm
.mov
.mp4
```

读取优先级也是 `.webm`、`.mov`、`.mp4`。扩展名大小写不敏感，例如 `.MOV` 也可以。

`source/` 是原始素材备份目录，不参与播放。

## 动作菜单

菜单项和动作映射：

| 菜单 | 动作 |
| --- | --- |
| 逗猫 | `play` |
| 喂食 | `eat` |
| 喝水 | `drink` |
| 摸摸头 | `touch` |
| 摸肚皮 | `happy` |
| 睡觉 | `sleep` |
| 散步 | `walk` |
| 设置 | 打开控制面板 |
| 退出 | 退出应用 |

## 动作规则

- 默认播放 `idle`
- `idle`、`sleep`、`walk` 循环播放
- `play`、`eat`、`drink`、`touch`、`happy` 播放一次后回到 `idle`
- 切换动作时有淡入淡出
- 缺少某个动作素材时不会崩溃，会在控制台提示
- 随机动作只会在空闲时触发，不会打断用户操作
- `walk` 会根据方向镜像视频，避免猫猫倒退

## 散步

当前有两种散步方式：

- 菜单点击“散步”：猫猫向左走，到达左侧边缘后回到 `idle`
- 拖到左右边缘松开：猫猫会向屏幕内或另一侧走，结束后回到 `idle`

原始 `walk` 素材按“朝左走”处理：

- 向左走：不镜像
- 向右走：使用 `scaleX(-1)` 镜像

## 控制面板

控制面板包含：

- 宠物大小：默认 `0.55`，范围 `0.25` 到 `1.0`
- 休息提醒：关闭、30 秒测试、15 分钟、30 分钟、45 分钟、60 分钟
- 小猫状态：心情、饱腹、水分、精力

控制面板是独立窗口，可以拖动。关闭按钮只关闭控制面板，不影响猫猫当前动作。

## 休息提醒

休息提醒会在设定间隔后显示气泡：

```text
主人该休息一下啦
```

气泡显示在猫猫上方，并带有猫叫提示音。单击气泡或单击猫猫后，气泡会消失。

提醒间隔会保存到 `localStorage`，下次启动自动读取。

## 小猫状态

小猫状态包括：

- 心情
- 饱腹
- 水分
- 精力

状态会随在线时间轻微变化：

- 饱腹会慢慢下降
- 水分会慢慢下降
- 精力会慢慢下降
- 如果饱腹、水分或精力太低，心情也会下降

动作也会影响状态：

- 喂食：增加饱腹和心情
- 喝水：增加水分
- 逗猫：增加心情，消耗精力
- 摸摸头：增加心情
- 摸肚皮：增加心情
- 睡觉：恢复精力
- 散步：增加心情，消耗精力

状态保存在 `localStorage`，下次启动会继续读取。

## 新增或替换素材

如果只是替换已有动作的视频：

1. 把新视频放进对应动作文件夹
2. 确认格式是 `.webm`、`.mov` 或 `.mp4`
3. 重启应用

如果要新增一个全新动作，例如 `angry`：

1. 在 `assets/cat/` 下新增 `angry/`
2. 把视频放入该文件夹
3. 在 `renderer.js` 的 `ACTIONS` 中加入动作名
4. 按需要加入 `LOOP_ACTIONS` 或 `ONE_SHOT_ACTIONS`
5. 在 `index.html` 的菜单里增加对应按钮
6. 按需要在状态系统中增加动作效果

## 当前限制

- 当前通过 `npm start` 本地运行，还没有打包安装流程
- 当前没有系统托盘；退出后需要重新打开应用
- 如果视频素材本身没有透明通道，窗口仍然透明，但视频里的背景会按素材原样显示
- 当前 Electron 配置偏向本地个人使用，正式分发前建议改为 `preload.js + contextBridge`
